
## 5.2 S&OP 그리드 구조

```
행 구조 (SKU 1개 = 5행 반복):
  ├─ 출고예상   ← 계획
  ├─ 실출고     ← 실적
  ├─ 입고계획   ← 계획
  ├─ 실입고     ← 실적
  └─ 마감재고   ← 계산

열 구조 (올펀 포뷰트, 258열):
  A~J : NO. / 확인필요 / 구분 / 재고관련 / 품번 / 바코드 / 상품명 / 이벗매니저 상품명 / 구분 / 기초재고
  K~  : 12개월 × 20열
        └─ 16채널 (자사몰·네이버·국내B2C·품고·쿠팡로켓·올리브영·국내B2B·아마존US·
                  아마존JP·해외창고·해외B2C·해외B2B·공구·마케팅&센터·CS·기타)
           + 그 외 조정 + 입고 조정 + 출고 조정 + 총 합계
```

> ⚠️ **창고마다 채널 구성이 다르다.** 올펀 16채널 / 품고 2채널(네이버·기타) / 로딧 2채널(통합·기타) / 미르글로벌 2채널.

## 5.3 핵심 수식 → 업무규칙

```excel
AD7 = SUM(K7:AC7)              ' 총 합계 = 16채널 + 그외조정 + 입고조정 + 출고조정
AD10 = J10 - AD7 + AD9          ' 1월 마감재고 = 기초재고 − 실출고 + 실입고
AX10 = AD10 - AX7 + AX9         ' 2월 마감재고 = 전월 마감 − 당월 실출고 + 당월 실입고
BR10 = AX10 - BR7 + BR9         ' ... 재귀
```

| 엑셀 수식 | 시스템 업무규칙 | 판정 |
|---|---|---|
| `마감재고(M) = 마감재고(M−1) − 실출고(M) + 실입고(M)` | `기말 = 기초 + 입고 − 출고 + 순조정` (재고 PRD §24.4) | ✅ **동치**. 단 시스템은 **원장 집계**로 산출하며 재귀 저장 안 함 |
| 조정 3종이 채널 합계와 같은 레벨에서 가감 | 승인된 `MANUAL_ADJUSTMENT` 거래 | ⚠️ **과거 조정값은 원장으로 전환 금지** (재고 PRD §25.1) |
| 헤더 r2 프로모션 배수 (`2.5`, `2.0`, `1.5`) | 계절·프로모션 계수 (올리브영 3/6/9/12월 전달 1.5배) | R5 `demand_forecast_factor` |
| 계획과 실적이 같은 표에 공존 | **완전 분리** (재고 PRD §4.4) | 🔴 구조 자체를 복제하면 안 됨 |
