## 1. SKU MASTER (DEEPPOINT_SKU_MASTER)
### 품번 규칙
- 본품: `브랜드(2) - 대분류(2) - 소분류(2) - 일련번호(3) [- 추가코드]`
  - 예: `BO-BT-TN-001`, `FB-OY-CW-001`
- 부자재: `완제품품번 + 구분코드(2) + 일련번호(2자리)` → 예 `FB-OY-CW-001-BX-01`
- 공용 부자재: `브랜드-CM-일련번호` → 예 `FB-CM-002`
- 보관처 분기: 공용부자재 + `_보관처축약코드(3)` → 예 `FB-CM-002-CLB` (갈렙이앤씨)

### 코드 마스터
- 브랜드: FB(포뷰트), BO(바디오라)
- 대분류(11): DV Device, TL Tool, SL Styling, HC HairCare, CV Cover, BT Beauty, ET Etc, ST Set, GB GiftBox, **OY 올리브영, DS 다이소, MS 무신사** (← 채널이 대분류에 섞여 있음)
- 소분류(19): IR/DR/HT/CW/SP/ES/SH/TR/TT/TN/TU/BM/AP/MN/SC/RF/PC/MG/ET
- 추가코드: GL/EU/JP/US/UK/CN/TW/CA (국가), BK(벌크=반제품)
- 부자재 구분코드(39): MC BX IB OB IN LB SL BT TB CP PP SP PK RF ZB SF MN CH TL HD BK MD RM ET / CT SB DP PM PG / CM FC FP SV DV SM LG CF DG
- 보관처 축약(11): BOC IJC CSM CLB MKM EZC CTK RBM JPS NNN BON

### 규모
- 최종 SKU MASTER: **490 품번**
  - 제품 부자재 240, 완제품 57, 소모품 52, 공용부자재 44, 기획세트 부자재 32, 미용실 24, 기획세트 완제품 15, 완제품(비매품) 7, 무형 6, 반제품 4, 기타 4, 부자재 2, 샘플 1, 금형 1
- ERP 구분 코드: 원재료 0 / 제품 1 / 반제품 2 / 상품 3 / 부재료 4

### 데이터 품질 이슈
- 바코드 `확인필요` 값 다수 존재
- 상품명이 4종 병존: 최종 상품명 / 기존 상품명(ERP) / 기존 상품명(WMS 이벗매니저) / 채널별 상품명(품고·로딧·쉽너지)
  → **채널별 상품명 매핑 테이블이 별도 엔티티로 필요**

## 2. BOM (DEEPPOINT_BOM)
### 시트
- `최종 BOM`: 완제품 80종 × 재고원가(VAT별도 / VAT포함 추정 1.1배)
- `BOM 상세_2026.06 기준`: **383행 / 모품번 80종** — 단일 레벨 전개
- `수입단가_2026.01~2026.06`: 수입 부자재 랜딩코스트 계산
- `중국 연휴 일정`: 춘절·국경절 → 리드타임 가산 규칙 (예: 디자인플래닛 5주 → 6주)

### BOM 상세 컬럼
구분(채널) / 브랜드 / 바코드 / 신규품번 / 신규상품명 / **BOM 분류코드** / **BOM 품번** / **공용 BOM 품번** / 부자재명 / 구분(완제품·반제품·부자재) / 상세항목 / **인아웃박스 입수량** / 상세사양 / **제조사** / **턴키·사급 구분** / **입고처** / **MOQ** / **리드타임** / Price(KRW) / 최근매입가(VAT별도) / 이벗매니저 상품명 / 이카운트 품번

핵심 특징:
- 완제품 행 자체가 "조립 임가공" 원가 라인으로 존재 (3PL 임가공비, 예 464원)
- 반제품(벌크)은 별도 품번(`FB-SL-CW-006`)으로 BOM 구성품에 들어감 → **2단계 BOM 구조**
- 공용 부자재는 `BOM 품번`(전용) ↔ `공용 BOM 품번`(대체) 2컬럼으로 표현
- **사급 / 턴키** 구분이 원가·발주 주체를 가름

### 수입 랜딩코스트 산식 (수입단가 시트)
```
부가비용 합계 = 통관수수료 + 국제운임 + 보험료 + 관세 + 포워딩비
분배          = 부가비용 합계를 B/L 내 품목별로 배분
발주금액(KRW) = 발주금액(USD) × 선잔금 환율 평균
                (선금 적용 환율, 잔금 적용 환율의 평균)
발주단가      = 발주금액(KRW) / 실입고 수량
개당 단가     = 발주단가 + 부가비용(vat별도) 배분액
```
→ B/L 단위 비용을 품목에 배분하는 로직이 핵심. **수입부가세는 원가 제외**

## 3. 구매·발주 (발주현황 워크북)
### 시트 구성
| 시트 | 역할 |
|---|---|
| 발주현황 | 국내 발주 마스터 (**477행 / 매입처 34곳**) |
| 입고현황 및 일정 | 발주 → 입고 예정/실적 트래킹 |
| 발주입고현황 및 일정 수입 | 수입 발주 (B/L·통관·환율·HS CODE) |
| 부자재 현황 | 제조사 보관 부자재 잔량 관리 |
| 지급조건 | 거래처 40곳 지급조건 + 계좌 |
| 월 지급계획 | 월별 현금지급 계획 |
| 거래처 정보 / 입고지정보 | 담당자·주소 마스터 |
| 메일 본문 양식 | 발주 메일 자동 생성 양식 |
| 수입시트 | **회사가 직접 작성한 수입관리 요구항목 스펙 (121행)** |

### 발주현황 컬럼
발주일 / 완제품품번 / **BOM 품번** / 상품명 / 매입처 / 구분 / **차수(2511차)** / 상세항목 / 구분2(복합키) / 납품요청일 / 발주수량 / 단가(VAT별도) / 발주금액(VAT포함) / 최초입고일 / 입고수량 / **차이** / 지급조건 / **선금(VAT포함) / 지급일자 / ✔ / 계산서 발행월** / **잔금(동일 4필드)** / 비고

- `구분2` = `상품명+매입처+구분+차수+상세항목` 문자열 결합 → **엑셀 임시 조인키** (플랫폼에서는 PO Line ID로 대체)
- `✔` 플래그: `C` = 지급요청 완료, `F` = 지급확정(예정)
- **차수**가 발주 배치 단위 (YYMM차)

### 지급조건 패턴 (40개 거래처)
1. `발주 시 50%, 입고 후 익월 10일 50%` — 최다
2. `입고 후 익월 10일 100%` — 최근 전환 추세 (2026.05~07부터 다수 변경)
3. `입고 후 익월 9일 100%` (본코스메틱)
4. `발주 시 70%, 입고 후 익월 10일 30%` (케이피엠)
5. `발주 시 50%, 입고 후 100%` (디자인플래닛)
6. `발주 시 50%, 납품 전 50%` / `납품 전 100%` (영동프라텍, 우성팩)
7. `발주 시 50%, 상품 입고 전 50%` + **USD 결제** (한일전자)
8. 수입: **T/T** (선금/잔금, 통관정산일 기준)

→ **지급조건 = (트리거 이벤트, 비율, 오프셋) 규칙 엔진으로 모델링 필요**
- 트리거: 발주시 / 입고후 / 납품전 / 통관정산일
- 오프셋: 익월 N일 / 즉시 / 출고 전
- 조건 변경 시 **적용 시작 시점(발주분 기준 vs 마감 기준)** 을 함께 관리해야 함
- 기안 규칙: *수요일 지출결의서 기안 → 그 주 금요일 지급*

### 월 지급계획 3단계 확정도
| 단계 | 의미 |
|---|---|
| 마감완료 | 지급 확정 (과거) |
| 입고완료 | 입고 완료 → 지급 확정 + 잔금 예정일 |
| 발주완료 | 발주시점 예상 지급일정 (입고일 따라 변동) |
| 합계 | 지급완료 + 지급확정 + 지급예정 |
- 국내 매입건만. **수입 건 제외** (별도 관리)
- 계산서 발행월을 별도 추적 (지급월 ≠ 계산서 발행월)

### 부자재 현황 (제조사 보관 재고)
```
부자재 잔량 = 부자재 입고합계(완료+예정) − 본품 발주합계(완료+예정) + 조정
```
- 공용 부자재는 여러 완제품 품번의 SUMIF 합산 (현재 하드코딩된 품번 문자열)
- 보관처(제조사)별로 재고를 분리 관리 → **사급 자재의 위탁재고(consignment) 개념**
- `부자재 현재 실재고` 는 실사 반영 컬럼

### 수입 관리 요구 스펙 (수입시트 — 8개 섹션 121항목)
1. 기본정보 — 발주일/차수/품목코드/구분/매입처/국가/**진행상태(발주·생산중·선적대기·선적완료·통관중·입고완료)**
2. 발주/계약 — PO No / PI No / CI No / 무역조건(EXW·FOB·CIF·DDP) / 결제조건 / 통화 / 적용환율
3. 송금 — 선금·잔금 각각 (비율·USD·송금일·적용환율·KRW) + 송금수수료
4. 생산/선적 — 생산완료예정/출고예정/선적예정/실선적/도착예정/실도착 / 운송방식 / 포워더 / **BL·AWB No** / 컨테이너 / CBM / 총중량·순중량
5. 통관 — 수입신고번호 / 신고일 / 수리일 / **HS CODE** / 관세율 / 과세가격 / 관세 / 수입부가세 / 관세사 / 통관수수료 / 검역비
6. 물류비 — 해외내륙 / 국제운임 / 적하보험 / THC / D/O Fee / Document Fee / 보세창고료 / 국내운송 / 상하차
7. 입고 — 입고창고 / 예정·실제일 / 발주·입고·**차이·불량·정상입고 수량** / 입고완료여부
8. **재고원가 계산 — 재고원가 산입액 ÷ 정상입고수량 = 재고단가** (수입부가세 제외)

## 4. 재고 (재고현황 워크북)
### 시트
| 시트 | 역할 |
|---|---|
| 재고현황 | **메인 대시보드** (완제품, 3PL 올펀) |
| 부자재 | 부자재 가용재고 |
| 1. 일별마감재고 / 마감재고 RAW | 일별 스냅샷 |
| 2. 현재고 | WMS 가용재고 스냅샷 |
| **3. 출고 RAW** | **15,667행** 출고 트랜잭션 |
| 월별출고량 | SKU × 월 × 출고(1)/출고(2) 피벗 |
| 입고 RAW | 입고 예정/실적 (발주 워크북과 동일 스키마) |
| 출고예정수량(홀딩전) | 해외/국내 출고예정 |

### 재고현황 핵심 산식
```
일평균 출고 B2C(3M) = 월별출고량[출고(1) 3개월평균] / 30
일평균 출고 B2C(1M) = 월별출고량[출고(1) 직전1개월] / 30
B2C MAX             = MAX(3M, 1M)
B2B 도 동일 구조 (출고(2) 기준)
최근 2주 B2C        = SUMIFS(출고RAW, 품번, 구분="A", 최근14일) / 14
최근 2주 전체       = SUMIFS(출고RAW, 품번, 최근14일) / 14

가용재고            = VLOOKUP('2. 현재고')
소진예상일 B2C      = 가용재고 / B2C MAX + 기준일
소진예상일 전체     = 가용재고 / (B2C MAX + B2B MAX) + 기준일
소진예상일(2주 B2C) = 가용재고 / 최근2주B2C + 기준일
1차 입고 후 재고    = 가용재고 + 입고예정수량 − 출고예정수량
1차 입고 후 소진일  = 위 / (B2C MAX + B2B MAX) + 기준일
2차 입고예정수량    = SUMIF(입고RAW 전체) − 1차 입고예정수량
```
- 입고예정 조회: `FILTER(입고RAW, 키=품번&"완제품", 실입고일="")` → **미입고 건 중 최초 1건**
- 조회 키가 `품번 & 구분` 문자열 결합 (구분3 컬럼)
- 플래그 컬럼: 단종 / 세트 / 확인필요
- 업데이트: 가용재고만 **오전 1회** 수기/스크립트 갱신

### 출고 RAW 구조
매칭사용자코드(품번) / 쇼핑몰 / 매칭관리명 / 매칭수량 / **출고일** / **구분(A/B)** / 종류(완제품·소모품) / 확인 플래그
- 구분 A = B2C계열, B = B2B계열 (매출구분·퀵확인 시트로 매핑)
- `#N/A` 매칭 실패 행 존재 → **SKU 매핑 실패 처리 큐 필요**

- `퀵 확인` 시트: **입고지 → 구분최종** (예 `[LA02] 양지센터` → F. 올리브영)

### S&OP 그리드 구조 (창고별 시트: 올펀·품고·로딧·미르글로벌)
- 행: SKU 1개당 **5행** = `출고예상 / 실출고 / 입고계획 / 실입고 / 마감재고`
- 열: `기초재고` + **12개월 × (채널 N개 + 그 외 조정 + 입고 조정 + 출고 조정 + 총 합계)**
  - 올펀(포뷰트): 16채널 + 4 = 20열 × 12개월 = 240열 (총 258열)
  - 품고/로딧/미르글로벌은 채널 수가 적어 열 구조가 다름 → **창고마다 스키마가 다름**

### 핵심 재귀 산식
```
총 합계(월M)   = SUM(채널1..N, 그외조정, 입고조정, 출고조정)
마감재고(1월)  = 기초재고 − 실출고(1월) + 실입고(1월)
마감재고(M)    = 마감재고(M−1) − 실출고(M) + 실입고(M)
```
- 미래월은 `출고예상`(계획) 행에 값이 들어가고, 과거월은 `실출고`가 채워짐
- 조정 3종(그 외 / 입고 / 출고)이 **채널 합계와 같은 레벨에서 가감** → 재고 조정·이월 처리
- 헤더 r2에 프로모션 배수 (`2.5`, `2.0`, `1.5`) → **올리브영 3/6/9/12월 이벤트 전달 1.5배** 등 계절 계수
- 파생 시트: `SKU별 실출고_올펀`(재고조정 제외), `SKU별 마감재고_올펀` → SKU × 12개월 평면 피벗
